# Repaso: Fundamentos de Python
 
Ejercicios de repaso para las semanas 1-2 de Geocomputación (1GEO20).
 
## Contenido
 
- `ejercicios_fundamentos_python.ipynb` — variables, tipos de datos, listas, tuplas, diccionarios, condicionales, loops, funciones y NumPy.
- `quickstart.ipynb` — introducción general a Python.
- `numpy-basics.ipynb` — fundamentos de NumPy.
